% =====================================================================
%  base-cv/cv-ats.tex : the ATS-friendly master CV
%
%  Identical CONTENT to cv.tex, styled for a parser rather than a person:
%  single column, no icons, no colour, linear reading order, a font every
%  extractor handles.
%
%  Build from inside this folder:
%      pdflatex cv-ats.tex
%
%  Why both: applicant tracking systems parse two-column layouts, icons
%  and ligature-heavy display fonts badly, and a CV that parses into the
%  wrong fields is a CV nobody reads. Attach this one to parsing portals
%  and the designed one wherever a human opens the file.
%
%  Neither PDF is attached under its own name. Every file an employer
%  receives leads with your name, so send a COPY named
%  <name>-cv-<company>-ats.pdf (<name> is the file-name slug in profile.md).
%  Keep the content identical to cv.tex: a correction to one goes into the
%  other in the same pass.
%
%  Content rules (CLAUDE.md): every claim traces to MASTER_CV.md, every
%  number verbatim, no em dashes, date ranges use "--".
% =====================================================================

% =====================================================================
%  templates/tailored-cv-ats.tex : ATS-friendly tailored-CV skeleton
%  Single column, no icons, no colour, linear reading order.
%
%  Usage (tailor skill):
%    1. Copy to applications/<company>-<role>/cv-<slug>-ats.tex
%    2. Replace every {{...}} placeholder. Same content rules as the
%       designed version (MASTER_CV.md only, numbers verbatim, no em
%       dashes). This is the version applicant tracking software parses:
%       mirror the posting's exact keyword spellings here, but ONLY where
%       the evidence exists in MASTER_CV.md. Mirroring a keyword the CV
%       cannot support is the polite name for lying.
%    3. Build with pdfLaTeX:  pdflatex cv-<slug>-ats.tex
%
%  Why a second file at all: parsers handle two-column layouts, icons and
%  ligature-heavy display fonts badly, and a CV that parses into the wrong
%  fields is a CV nobody reads. Attach this one to parsing portals and the
%  designed one wherever a human opens the file.
%
%  This file is a skeleton; it is not meant to compile until the
%  placeholders are replaced.
% =====================================================================
